PUBLISH WITH GITHUB PAGES
1. Extract this ZIP file.
2. Create a public GitHub repository (for example: bawa-technology-portfolio).
3. Upload ALL files above directly into the repository root (not the ZIP file).
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish and open the generated URL.
8. Test every page, navigation link, email/phone link, and mobile layout.
